# Semana 04 — Estruturas de dados

Execute com `python3 main.py`.

O programa cadastra produtos em uma lista, filtra por preço, ordena de forma crescente e decrescente, cria um conjunto de categorias e calcula uma tupla de estatísticas. Ao final, apresenta uma equivalência didática usando vetor de tamanho fixo, bubble sort e simulação manual de conjunto.

Também há uma versão comentada em `main.por`, com vetor e bubble sort.
